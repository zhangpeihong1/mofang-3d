# 银河魔方 · Cosmic Cube

React + TypeScript + Vite + Three.js 的交互式银河魔方。

![01-desktop](.\assets\01-desktop.png)

## 本地预览

本次交付已启动：**http://localhost:5174/**

重启电脑或关闭服务后，在项目目录执行：

```sh
npm ci
npm run dev
```

已有依赖时只需 `npm run dev`。使用支持 WebGL 2 的现代浏览器；首次准备纹理时会显示加载提示。当前环境使用 Node.js 24，依赖版本由 `package-lock.json` 锁定。场景、字体和纹理均无需外部网络资源。

## 操作

| 操作 | 方法 |
| --- | --- |
| 观察角度 | 鼠标拖拽；触屏单指拖拽 |
| 缩放 | 鼠标滚轮；触屏双指缩放 |
| 表层转动 | 点击 U / D / L / R / F / B，或按对应字母键 |
| 中层转动 | M：X 轴中层；E：Y 轴中层；S：Z 轴中层 |
| 反向转动 | 选择「逆向」；Shift + 字母键临时反转当前方向 |
| 打乱 | 随机执行 18 次表层转动，执行时避免重复打乱 |
| 撤销 | 撤销上一步，直到返回初始状态；步数同步减一 |
| 复位 | 立即取消待执行动作，将六面还原；保留当前观察角度 |
| 自动巡航 | 自动缓慢自转，拖拽期间暂停，松开后稍后继续 |
| 音效 | 默认关闭，开启后播放程序生成的机械反馈音 |

U / D / L / R / F / B 的顺向遵循从对应面外侧观察的顺时针；M / E / S 遵循标准中层记号。界面方向对应魔方的固有坐标，拖拽视角不会改变字母含义。

## 已完成功能

- 27 个独立小方块、54 块圆角色片；每次整层恰好转动 9 个小方块。
- 在魔方局部坐标内执行转层；每次转动后校准位置和朝向，避免浮点误差累积。
- 10,120 个星点、三层 1024 × 1024 星云纹理、七组循环流星。
- 1024 × 1024 微表面纹理、物理材质、清漆高光与 PMREM 环境反射。
- 2048 × 2048 柔和阴影、ACES Filmic 色调映射、HDR 辉光后期与 sRGB 输出。
- 桌面、手机、平板布局，键盘焦点提示，加载/失败提示，遵循系统减少动态效果偏好关闭默认巡航。
- 复位复用模型与材质，退出时释放几何体、纹理、后期缓冲、阴影和音频资源。

## 构建与验收

```sh
npm run build
npm run preview
```

生产构建产物在 `dist/`；生产预览使用 http://localhost:4173/，与开发预览端口分离。

```sh
npm run capture -- --round=3
```

自动验收使用本机 Microsoft Edge 无头浏览器，默认访问 5174。可通过 `DEMO_URL`、`SHOT_DIR` 环境变量指定地址及输出目录。需要已安装 Microsoft Edge；其他环境可将脚本的 Playwright `channel` 改为其已安装的浏览器。

三轮截图和完整检查结果保存在 `artifacts/`，详情见 [验收记录](artifacts/ACCEPTANCE.md)。最终轮 35 项检查通过，控制台错误、运行时错误和失败请求均为零。生产构建通过；打包器提示 Three.js 所在单个 JS 包超过 500 kB（压缩传输约 221 kB），不影响本地运行。

辅助验收地址 `?test=1` 会停止自动动画，供脚本逐帧推进；`?test=1&studio=1&view=front` 可检查纯模型，view 另支持 side / rear / top。正常操作请使用不带参数的预览地址。
